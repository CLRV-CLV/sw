# 跨平台内容中枢（第一阶段）

入口 `/connections`，账号设置页也有链接。本站登录独立于任何平台。

## 已实现与未实现

| 平台 | 实现状态 | 展示范围 |
| --- | --- | --- |
| GitHub | OAuth 后端和展示已实现；部署者配置应用后可使用，当前预览未配置、未真实联调 | 资料、最近更新30个以内公开仓库、最多30条公开活动；非所有账号信息 |
| bilibili | 手动 BV/完整视频链接收藏 + 官方播放器；尚无账号登录/自动内容导入 | 点击后加载远程 iframe；播放受版权、区域、登录、平台嵌入政策限制 |
| 抖音 | 仅明确标记为待接入 | 尚无授权、图文/视频同步或播放器 |
| 其他 | 未接入 | 不显示虚假连接/导入成功 |

GitHub 连接会在 GitHub 官方授权页完成，回到本站展示；不是以第三方 Cookie/密码代登录。应用不得要求用户提供第三方密码或复制会话 Cookie。抖音/bilibili 的账号内容需要官方开放平台审核与授权接口，不能从其他站点或本地浏览器窃取会话来替代。

## GitHub 部署

在 GitHub 创建 OAuth App，callback URL 精确填写：
`https://你的域名/v1/connections/github/callback`

运行服务前通过安全环境变量配置：
- `GITHUB_CLIENT_ID`
- `GITHUB_CLIENT_SECRET`
- `GITHUB_REDIRECT_URI`（上面的完整 URL）

不要把真实 secret 写进仓库或前端；生产必须 HTTPS。预览地址变化时需要同步修改应用回调地址。请求的 scope 仅 read:user，无仓库写入权限，不申请读取私有仓库、私信或全部邮箱。OAuth state 服务端随机生成、10分钟有效、绑定本地账号并一次性消费；API 需要本站登录。

token 仅保存在服务端内存，不返回给前端，也不写入数据库，重启后需重新授权。本阶段不支持长期加密凭据存储、刷新令牌或多 GitHub 账号。断开连接只清除本站内存令牌；如要撤销平台授权，需在 GitHub 的 Authorized OAuth Apps 中手动撤销。第三方接口有15秒超时，错误不泄露上游凭据。

## 不下载媒体的边界

服务端不下载/转存视频文件。bilibili 仅保存 BV 标识到本浏览器 localStorage（最多50条），点击时载入官方 player.bilibili.com 页面，不预加载视频、不解析直链、不提供下载按钮。浏览器正常缓冲、缓存视频是播放所必需，无法承诺“设备上绝不出现任何媒体字节”。iframe 可能包含平台自带链接，本应用不主动跳转，但也不能控制跨域播放器内部导航。无法嵌入的内容不绕过平台限制。

目前没有自动导入平台视频/图文、关注列表、私信，也没有保证所有内容都能在本站播放。GitHub 网络接口在此环境可用；抖音/bilibili 主机不在沙箱出站许可内，本轮无法进行真实平台播放/授权验证。
