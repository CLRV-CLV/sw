# 全量补齐台账（不是“全部完成”声明）

本台账承担后续主动排查和实现，不要求用户逐个寻找断点。路径盘点：`api-contract-inventory.json`（可用 `node scripts/audit-api-contracts.mjs` 重建）。它是前端 `useApi.ts` 的静态路径清单，不能代替方法级测试，不能覆盖全部旧敲敲调用，更不能用“返回200”证明功能完整。

## 本轮实际接通并有回归测试的部分

- 签到、连续签到、排名、每日经验及等级门槛；北京时间04:00换日，签到10丁尼，经验6至10；首次发布/评论/点赞分别4/3/1经验，每日只奖励一次，总上限50。签到幂等，已签到重复请求不重复发奖。
- 钱包、投币、一键三连、丁尼流水；站内直接转账有发送人幂等键、余额约束、双方事务记账；管理员丁尼调整写流水。虚拟资产不是现实货币。
- 关注、屏蔽、关注流、未读记录、屏蔽列表、搜索和标签联想。账号页屏蔽与敲敲黑名单同步；匿名委托不会通过作者主页/关注流暴露归属。
- 匿名委托及匿名评论的展示和保存；公开响应隐藏作者ID，管理数据库保留归属。匿名展示不是端到端匿名，图片复用、正文等信息仍可能被关联。
- 普通作者删除帖子/评论，级联清理评论和反应；作者对评论置顶/采纳；访问草稿的评论回复失败关闭。
- 举报提交/查重、后台举报处理及审核日志。
- 账号安全概览、当前/其他会话、会话撤销；会话ID为令牌摘要，不输出真实会话令牌；昵称修改、简介/隐藏、个人展示委托、基础头像与名片选择。
- `/activity` 私人日程CRUD、通知读取/已读、钱包转账入口；评论触发持久化私有通知。日程只有站内到期标记，不是系统后台推送；通知页当前手动刷新，不是全事件通知中心。
- B站完整链接/BV号校验、官方播放器嵌入保存；没有抓取标题/封面/时长，不冒充真实元数据。无法获取封面时编辑器用明确的默认封面。
- 委托页撤销上一版独立荧光绿海报与工作台编号。首页和委托页使用同一个 `TerminalMasthead.vue`，其余复用主页卡片材质/圆角变量；保留首页已有大横幅、主导航形状及呼吸动画。原生草稿导航替代旧ZMenu金属框。新视觉还没有用户验收。
