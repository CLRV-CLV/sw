# 图片上传与存储

当前已打通：站点图标/背景、后台用户头像、驻站AI头像、用户自定义头像、帖子封面、正文编辑器图片、评论图片。既可上传，也可在提供地址的设置处保留手动填地址。原有敲敲私有附件仍走成员权限接口，不会改为公开图片。

- PNG / JPEG / WebP / GIF，单张不超过30MB；不接受SVG、HTML或其他文件伪装成图片。
- 上传必须登录且账号未封禁；签名、上传、完成与图片引用均校验所属用户。
- 上传服务使用同源相对路径，无需配置S3。图片字节与元数据存放在现有 `DATA_DIR/interknot.sqlite`；更新时随数据库保留，备份时需要完整保留数据库（运行中备份应使用SQLite备份机制，不能只复制主文件忽略WAL）。
- 每账号图片存储配额200MB，最多20个待上传任务，15分钟凭证过期。图库移除仅隐藏入口，避免破坏既有文章/头像链接；这不会释放配额，目前没有后台物理清理界面。
- 这些是供头像、背景及文章使用的**公开图片**，获得地址即可访问。不要上传私密内容。静态图片响应固定图片MIME、`nosniff`与限制性CSP，完成后不可覆盖原URL。
- 后台站点外观、用户头像和AI头像上传后须点击对应保存按钮；正文图片上传后插入正文，随草稿/帖子保存。
- 正文编辑器支持在 Markdown/HTML 源码、富文本模式上传并插入图片。帖子最多9张封面，图片评论也支持无文字发送。非图片附件、视频不在此上传模块范围内。

Wiki自动头像目前引用原站CDN，不是下载镜像；如存在防盗链/原站不可用，可手动上传替代。
