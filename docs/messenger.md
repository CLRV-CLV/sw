# 敲敲当前实装范围

入口 `/messages`；首页“敲敲”快捷入口与原敲敲弹窗内“通讯录 / 群聊 / 文件”链接均可进入。原弹窗的私聊REST/收件箱接口使用同一后端；本轮新增的群管理、附件与搜索界面在 `/messages`，不代表旧弹窗的所有演示入口已接通。

## 已实装
- 真实账号通讯录、账号/昵称查找、一对一私聊。
- 好友申请、接受/拒绝、双方好友关系、私有备注/分组、删除好友、黑名单。黑名单会阻止双方建立/发送私聊、好友申请与私聊输入提示；并不将同群成员自动踢出或过滤群消息。
- 私有群聊与公告频道（频道仅群主可发布）。群主邀请/移除、改名、转让、解散；普通成员退出。默认最多100人、每人最多创建50个群；不是公开频道发现/订阅系统。
- SQLite持久化会话与消息，重启保留。会话/历史分页、文本引用、本人编辑/撤回、会话内服务端关键词搜索及分页。
- 消息置顶列表（每会话50条；群/频道仅群主可管理，私聊双方可管理），与会话置顶分别处理。
- 文件和图片发送、受鉴权的下载；图片内联预览。音频文件播放与浏览器录音发送（最长60秒，依赖HTTPS、麦克风授权和浏览器MediaRecorder支持）。单文件最多5MB，每账号已存附件100MB；文件和元数据一并保存在SQLite，在线备份会包含附件。
- 已读/未读、会话置顶/免打扰、私聊隐藏及新消息重现。
- WebSocket按会话成员投递；注销/封禁后旧连接不再接收私聊事件。被移出/主动退出群立即失去消息和文件访问权限。
- 新加入（包括退出后重新加入）的成员不能读取加入前消息、搜索结果、置顶消息、引用或文件。群解散删除该群消息及附件；撤回文件消息删除其在线附件数据。

## 安全与限制

- 不是端到端加密；管理员需保护SQLite及备份。软撤回和删除在线附件不等于抹除历史备份。
- 图片检查文件头，禁止SVG等主动内容图片内联；通用文件以`application/octet-stream`附件下载，设置`nosniff`。附件路由仍校验当前会话成员和加入时点，没有公开静态文件链接。
- 通讯录从最近500个账号中查询，每次最多显示50人；它不是无限全站目录。独立消息页每页50条会话，可以加载更多。
- 服务器每账号每分钟限制120次敲敲写操作（含已读/管理操作）；这不是完整的反垃圾服务、病毒扫描或文件安全审计。
- 免打扰目前是会话偏好标记，尚未接入系统级推送服务。
- 浏览器自动化验证了文本私聊/群聊、好友、文件下载权限、搜索、移除成员和移动后台；真实麦克风采集/音频设备兼容性没有在此沙箱进行硬件验证。

- 丁尼红包/转账及可审计的资产流水、动态圈。
- 表情/贴纸管理、AI工具调用。驻站文字角色AI已接入New API配置、服务端上下文和Wiki档案审核，详见[驻站AI](resident-ai.md)；需配置真实模型后启用，不代表默认已有所有角色的已审核资料。
- 系统/移动推送、公开频道发现、超大群与对象存储/流式大文件。
