# 邮箱账户流程

新增真实 SMTP 适配器（Nodemailer）；不是开发环境回显验证码。默认不启用，缺少或无效配置不会阻断已有本地用户名/密码账户，也不需要第三方登录。

## 配置

在部署根目录 `.env` 设置，切勿在聊天/仓库公开凭据：

```ini
SMTP_HOST=smtp.your-provider.example
SMTP_PORT=465
SMTP_SECURE=1
SMTP_FROM=noreply@your-domain.example
SMTP_USER=your-smtp-user
SMTP_PASSWORD=your-smtp-password
SMTP_ALLOW_INSECURE=0
```

`SMTP_FROM` 是纯邮箱地址，不使用“显示名 <地址>”格式。端口587使用 `SMTP_SECURE=0`，仍强制STARTTLS；证书验证不会关闭。`SMTP_ALLOW_INSECURE=1` 仅供本地协议测试，生产勿用。超时及发送错误只返回通用错误，不泄露邮件服务响应和密码。

已有部署通过正常 `update.sh` 安装新增服务端依赖并重启；手动维护者需在 `server` 运行 `npm ci` 后重启。无需删除/重新建立数据库。密钥自动存于 `DATA_DIR/.email-code-key`，权限0600，需与数据库一起私密备份。修改或丢失它会使未完成的验证码失效。

## 功能与约束

- 登录弹窗默认本地账户；可切邮箱验证码登录/注册，也可通过绑定邮箱找回密码。
- 邮箱注册验证后直接建立HttpOnly会话；首个全新账户管理员规则与本地注册一致。公开昵称不使用邮箱，邮箱只在自己的安全信息和会话响应中返回。
- 已有本地用户在“我的 → 账户安全 → 绑定邮箱”绑定；支持用绑定邮箱及密码登录。邮箱唯一；已绑定后禁止直接换绑，防止只持有旧会话的人随意改绑。
- 密码10–200字符，使用现有scrypt存储。重置撤销此账户所有旧会话和验证码；修改密码后必须重新登录。其他账户的会话不受影响。
- 验证码有效10分钟，6位随机数；数据库只保存服务端密钥HMAC，不保存明文；按用途和绑定发起者隔离，成功即销毁，5次错误后失效。
- 同邮箱/用途/发起者60秒冷却；每邮箱10次/小时，每直连IP30次/小时，限额存数据库、重启不重置。反向代理后使用直连IP，不信任用户可伪造的X-Forwarded-For；同代理用户共享30次上限，尚无可信代理分级配置。
- 未注册邮箱的登录/重置、已有邮箱的再次注册发码返回统一确认结构且不发送邮件；界面使用“若邮箱已绑定账号”的提示。此举不保证网络时序完全一致。
- 未配置SMTP时，发码返回503且页面明确禁用邮箱入口；配置字段齐全只代表可尝试发送，不代表服务商凭据/域名已验证。生产仍需配置SPF/DKIM/DMARC并实测投递。
- 不包含账号注销、邮箱解绑/换绑、米游社认证。这些不因邮件能力接通而自动变成完成。

## 回归

```sh
node --test server/email-auth*.test.mjs
node scripts/check-email-browser.cjs
```

HTTP集成测试通过真正的本地SMTP协议接收邮件，验证邮件投递→一次性验证→注册/登录/绑定/重置→重启持久化，不是仅模拟返回200。浏览器脚本需要Chromium（可设置 `CHROMIUM_PATH`、`CHROMIUM_ARGS`）。本地SMTP测试不代表生产发信域名已验收。
