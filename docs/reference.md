## 导航交互最终区分

- 同类导航处于一条连续的圆角点阵轨道内，边框与搜索框同类；不是独立按钮拼接。
- 未选中且未悬停：不画独立底板或外框。
- 未选中且悬停/键盘聚焦：只画透明内部的灰色轮廓，并仅缩放轮廓。
- 点击成为选中项：绿色实心底板呼吸缩放，文字与命中区域固定。
- 按下：当前底板/轮廓收缩；绿色仅由真实选中状态控制，不由 hover 触发。
- 移除底板的方形阴影，SVG 轮廓允许溢出，避免缩放被视口裁成方框。
- 已选中项悬停仍保持其选中绿色；减少动态效果设置禁用循环动画。

本轮通过浏览器计算样式断言：灰色 hover 内部透明、SVG fill 为 none，点击后才
出现绿色、无底板阴影、文字 transform 为 none；390/360px 无横向溢出。

### 导航缩放再次校正
用户明确要求不是仅改变长度，而是沿导航胶囊轮廓整体放大/缩小，包含“最新”所在的 feed 栏。两排选中底板统一采用 inset 从 `3px 7px` 到 `-3px 1px`，横纵各边均扩张 6px；保留 `999px` 圆角，用轮廓偏移避免非等比 transform 把圆头拉扁。文字/命中区不动、灰色 hover 不动、减弱动态设置继续生效。
重新查阅 share121/inter-knot commit 66b275a 的 `lib/components/my_tab.dart`：底板 first/last/middle 分支仍为空 Container；AnimatedContainer 仅用于 trailing 的宽度过渡，没有可直接移植的绿色呼吸实现。不将此动画声称为上游已有代码。

最新补正：固定 6px 的左右变化在宽屏上不明显。两排绿色选中底板现统一由 `inset:3px 10%` 呼吸到 `inset:-2px 1%`，横向按各自标签宽度变化、纵向同时变化，圆角保持胶囊形。浏览器在 1440px 下采样确认：推送底板左右各从约34px收至3px；最新底板左右各从约25px收至2.5px，非仅纵向变化。

### 统一持续呼吸与贴边（覆盖上述各轮独立参数）
