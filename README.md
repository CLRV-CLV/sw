# 绳网 · 独立服务开发版

参考 [share121/inter-knot](https://github.com/share121/inter-knot) 的界面与交互，
不使用其 GitHub 登录 / Discussions 数据服务。详见 [参考记录](docs/reference.md)。

## 运行网页与 API

需要 Node.js 22.13+，无需外部数据库：

```sh
cd web && npm ci && cd ..
cd server
npm ci
npm run build:web
npm start
```

浏览器打开 `http://localhost:3000`。网页、API 和媒体由同一服务提供，监听
`0.0.0.0:3000`。`GET /health` 检查存活。网页点击登录即可本地注册，
不需要 GitHub、邮箱验证码或默认共享密码。用户名2–40字，密码至少10字符。

构建静态文件位于 `server/public/`（不入 Git，可由源代码重建）。
数据保存在 `server/data/interknot.sqlite`（不入 Git，升级前请备份）。
生产环境请使用 HTTPS 反向代理、启用 WebSocket 转发，并设置 `SECURE_COOKIE=1`。

## 当前实现范围

- 独立注册、scrypt 密码哈希、HttpOnly Cookie / bearer 会话与退出。
- 网页账户弹窗替换为本地账户，无 GitHub / 米游社登录要求。
- 信息流、分区和标签过滤、关键词搜索、热门排序与帖子列表分页。
- 文本草稿创建/编辑/发布；未发布内容不出现在公开详情或信息流。
- 帖子详情、嵌套评论、回复、点赞与收藏；点赞/收藏写入幂等。
- WebSocket 连接、握手、ack 与帖子发布广播（尚非完整实时通信服务）。
- 同源图片保持本地路径，移除 Cloudflare 统计脚本。

## 未完成 / 不应当作生产版本

仍在逐步适配上游界面，部分按钮会请求未实现的接口。匿名、媒体上传、富媒体评论和
外部视频暂明确拒绝，不伪装保存成功。关注、通知、考试/等级经济体系、完整敲敲群聊/
通话、AI 服务、办公套件、原生桌面、Android/iOS 安装包、更新脚本与发布 PR 均未完成。
目前种子世界为演示内容，不代表联网角色 AI。完整 1:1 视觉还原亦未验收。

尚需登录速率限制、部署安全审计、测试扩展和依赖漏洞处理后再公开部署。
当前来源校验为同 Host 的基础防护，不等同完整生产安全审计。
没有可用的 IPA / APK 发布物；iOS 真机分发需合法 Apple 签名配置。

### 设计方向确认

保留用户认可的绿色交互和大横幅；非官方参考仓库只用于借鉴，不覆盖产品取舍。
导航的绿色底板独立呼吸缩放，文字与点击区域不缩放，按下收缩；遵循减少动态效果设置。

导航交互区分：同类项目合在连续圆角栏中；未选中 hover 只显示灰色空心轮廓，
点击选中后才显示绿色底板；轮廓/底板缩放，文字与点击区域保持固定。

桌面Web（≥1025px）现有独立的双排页头与通栏导航，H5底栏不在桌面显示。
交互以最新要求为准：灰色悬停外框静止；绿色选中底板保留呼吸缩放，文字不缩放。
这只是桌面框架首轮，完整模块仍按上文未完成列表推进。

### 自动 / 强制布局
- `/`：默认根据窗口宽度自动适配 Web / H5。
- `/web`：强制桌面 Web，最小布局视口 1280px；手机上等比缩放以完整显示。
- `/h5`：强制 H5，最大布局视口 430px；宽屏上居中显示。
- 两个强制入口使用同源布局视口，让 CSS 断点、瀑布流计算、固定定位弹窗一致切换；账户和数据共用。站内导航保留在该模式中，外层地址保持入口路径。直接访问 `/` 恢复自动，不写入永久偏好。这仅为 Web 的布局切换实现，与原生桌面客户端无关。

### 跨平台内容中枢（第一阶段）
入口 `/connections`：GitHub OAuth 接入代码（需部署者配置应用）、公开资料/仓库/活动展示；bilibili 手动 BV 链接官方嵌入播放器。抖音授权与账号视频/图文自动导入尚未实现，页面如实标记待接入。不会抓取第三方密码或会话，也不下载视频到服务器。配置、权限及播放限制见 [平台接入说明](docs/connected-platforms.md)。

### 管理后台

`/admin`、`/web/admin`、`/h5/admin` 提供帖子/评论编辑删除、用户权限/封禁、会话撤销、注册/新建帖开关、操作日志。服务端独立校验管理员权限，无默认管理员密码。全新空库默认首个注册用户成为管理员，旧库可用 `ADMIN_USERNAMES` 指定已注册账号，详见 [后台与演示数据说明](docs/admin.md)。演示帖子来自 `server/seed.mjs`，不是抓取真实平台；一次性种子标记避免后台删除后重启又被补回。

### 宝塔 / Node.js 部署

本项目是 Vue/Nuxt/TypeScript 前端 + Node.js JavaScript 后端 + SQLite。宝塔选择 **Node.js 项目**，Node **22.16+**（建议22.22+），运行目录 `server`，启动命令 `npm start`。首次部署、Nginx/WebSocket、管理员与数据保留更新详见 [宝塔部署指南](docs/baota-deployment.md)。

更新：`./update.sh` 默认来源为 `arena/fd457726-sw`，`./update.sh main` 指定分支。更新前在线备份SQLite与.env，拒绝覆盖本地改动；宝塔自带进程管理时构建后需在面板重启，或使用独立PM2自动重启（二者二选一）。

### 本站资料、外观和敲敲

管理员首页提供后台入口。后台拥有独立管理导航，支持站点标题/图标URL/背景图/颜色，以及用户昵称/简介/头像URL/等级/经验/丁尼/菲林设置。个人空间已接通真实注册账号。普通用户的菲林仅标为珍贵货币。

`/messages`接入真实一对一私聊、SQLite消息持久化、引用/编辑/撤回、已读/未读、置顶/免打扰，以及成员隔离的WebSocket事件。原敲敲弹窗的私聊接口也使用这一后端。**群聊、语音视频、文件消息和真实AI仍未完成**，详见[敲敲实装范围](docs/messenger.md)。
