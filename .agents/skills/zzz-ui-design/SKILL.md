# 绳网 UI 设计 Skill

## 目标与适用范围

将已经过用户迭代确认的视觉与交互规律迁移到新页面，而不是只复制一组 CSS。默认适用于本仓库的 Web/H5；可为原生客户端提供视觉规范，但不得据此用 WebView 代替原生 GUI。

这是项目自己的参考型设计体系，**不是官方规范，也不代表已经完成 1:1 复刻**。外部开源项目仅是灵感与实现参考；保留许可证，不冒充官方素材或实现。

## 何时使用

- 用户要求“延续当前 UI”“绝区零味道”“做新的绳网模块”。
- 调整顶部导航、feed 筛选、H5 底栏、按钮底板或呼吸动画。
- 修复灰色轮廓、斜切圆角、移动端比例、桌面布局或旧样式穿透。
- 审查一个页面是否只是黑绿配色、却缺少当前项目的形状和层次语言。

不负责第三方账号授权、媒体权限、后端业务或安装包构建；不得用视觉完成度掩盖功能尚未实现。

## 开工前先读

1. 读用户最新要求；明确是局部微调还是改动整个体系。**新的明确指示优先于本 Skill。**
2. 看当前组件和浏览器效果，不把历史说明中的旧参数当成现状。
3. 读 [视觉与布局](references/visual-system.md)。
4. 涉及按钮时读 [导航轮廓与动态](references/navigation-motion.md)。
5. 按 [实现及验收](references/implementation-checklist.md) 检查实际渲染结果。

## 必须守住的设计原则

### 1. 是街头终端，不是普通 SaaS 换皮

保留深色终端底、酸性绿强调、粗重标题、点阵轨道、海报式大横幅及不对称细节。首页使用有内容密度的封面流与清晰文字层级。不要用满屏荧光、发光阴影和随机斜切来制造“风格”。

### 2. 先有结构，再有装饰

桌面 Web 有自己的宽屏布局，不是把 H5 拉大：账户/搜索工具行与接近通栏的主导航分层。H5 收紧布局、采用底部主导航。页面的阅读顺序和任务入口必须清楚。

### 3. 分离命中区、文字和底板

按钮本体只是稳定的交互区域。文字、图标不跟着呼吸缩放；独立底板承担形状与动态。选中按钮本体不得残留旧绿色背景、阴影或旧指示器。

### 4. 一组导航是一条连续轨道

不是每项套一个独立圆框。轨道整体圆角；组内底板区分左、中、右位置。共享轨道与单项轮廓是不同层，不能误把外层轨道当成待删除的旧按钮层。

### 5. 圆润的斜切，而非硬切多边形

- 第一项：圆弧左端、圆滑斜切右端。
- 中间项：两侧同向斜切，圆角过渡的平行四边形；左右各延伸 6px。
- 最后一项：圆滑斜切左端、圆弧右端。
- 实心绿底与空心灰框必须同源生成，不能分别绘制两套形状。

### 6. 有节奏，但只动该动的层

当前确认版：**800ms、非匀速分段缓动、以完整底板为基准向外 4% 呼吸**。中心固定，不左侧锚定，不先缩到轨道里面。灰色悬停框静止；文字与命中区域静止。手机、桌面、feed 使用同一动态契约。尊重减少动态偏好。

### 7. 修复根因，不叠加猜测

遇到“改了却没变”“底下露出旧按钮”，先查 computed style、scoped CSS 优先级及旧 DOM 层。不能只在文件末尾无限堆覆盖，也不能用截图之外的静态字符串测试声称视觉已通过。

## 推荐执行流程

1. **锁定范围**：写清将改哪一层，哪些用户认可部分不动。
2. **复用来源**：优先复用现有几何函数、布局断点、字体及动画；不再造第二套。
3. **最小改动**：对现有参数微调，不顺手重做用户已认可的横幅/配色/桌面结构。
4. **检查各状态**：普通、hover/focus、选中、切换、动画基准/峰值、减少动态。
5. **浏览器验证**：至少手机与桌面各一档；导航改动推荐 360/390/430/1440px。
6. **回归测试**：运行相关单元、类型检查及构建；浏览器断言检查真实宽高和底层透明度。
7. **交付说明**：短述具体变更和验证，清楚标注尚未视觉核验的部分。

## 禁止回退的方案

- 把所有底板重新做成完整胶囊，丢失左中右差异。
- 生硬 polygon 裁切、窄角尖刺，或拉伸整张小 SVG 导致圆弧被横向拉扁。
- 按住左边框只伸缩右边；只变长度或只变高度。
- 将当前呼吸改回匀速，除非用户明确再次要求。
- 呼吸文字、图标、按钮命中区；让灰色空心框也一起呼吸。
- 使用旧实体选中背景遮住新轮廓的空缺。
- 为模仿参考项目而删除已获认可的绿色方向和首页大横幅。
- 仅跑单元测试便宣称手机/桌面视觉完全正确。

## 仓库中的实现来源

- `web/app/utils/nav-geometry.ts`：圆润斜切路径和实心/空心掩码。
- `web/app/plugins/nav-geometry.client.ts`：测量实际尺寸、区分首中尾、中间额外宽度。
- `web/app/assets/styles/reference-alignment.css`：最终导航与布局规则。
- `web/app/assets/styles/interknot-art-direction.css`：首页海报/内容流视觉基础。
- `web/app/components/AppHeader.vue`、`HomeFeedNavigation.vue`、`MobileBottomNav.vue`：三组导航。
- `web/tests/unit/nav-geometry.test.ts`、`green-ui.test.ts`：几何与设计回归。
- `web/tests/e2e/mobile-nav.spec.ts`：移动布局与动态浏览器回归。

这些路径相对仓库根目录；移植到别的项目时迁移原则和参数，不假定这些文件存在。
