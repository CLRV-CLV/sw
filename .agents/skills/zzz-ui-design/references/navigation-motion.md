# 导航轮廓与动态：当前确认版

## 三层结构

1. **连续轨道**：一组导航共有的深色点阵底及灰色外框，静止。
2. **单项底板**：绿色选中实心或灰色悬停空心，使用同一几何路径。只有选中绿色底板呼吸。
3. **交互与内容**：透明按钮本体承载可访问属性和稳定命中区，文字/图标始终不缩放。

尤其注意：外层轨道整体圆角是有意保留的；应清除的是按钮本体残留的旧实体背景、胶囊边框、阴影或 TabsIndicator。

## 圆润斜切几何

应测量实际按钮宽 `w`、高 `h`，不要把110px宽的SVG直接拉到350px宽。

当前参数（见 `nav-geometry.ts`）：

```text
r = h / 2                         # 圆端半径，只与高度关联
s = min(16, w * 0.18)              # 斜切水平偏移
c = min(h * 0.32, (w - s) * 0.24) # 转角退让距离，40px高时约12.8px
L = hypot(s, h)
dx = s * c / L
dy = h * c / L
```

斜边转角使用二次贝塞尔 `Q`，控制点位于原顶点，沿相邻直边和斜边分别退让相同距离，让进入和离开方向均相切。不要恢复早期约5px的小转角，也不要只用 polygon 硬切。

- `first`：左端半圆，右端圆润斜切。
- `middle`：左右均斜切，上下边水平，两个斜端同向。
- `last`：左端圆润斜切，右端半圆。

首中尾由同一组的实际按钮列表决定，不将中间发布容器误计为导航项。绿色 `fill` 和灰色 `outline` 从完全相同的路径产生。灰框使用空心描边，不用半透明实心色冒充空心。

### 中间项额外宽度

中间项 `--ik-plate-extra:6px`，首尾为0。底板采用：

```css
margin-inline: calc(0px - var(--ik-plate-extra, 0px));
```

因此中间底板的静态宽度及整个动画都额外增加12px。标签位置、布局占位与命中区域不变，不通过加大字体或挤压相邻标签实现。

## 呼吸契约

```css
animation: ik-nav-plate-breathe 800ms ease-in-out infinite;

@keyframes ik-nav-plate-breathe {
  0%, 100% {
    inset: 0;
    animation-timing-function: cubic-bezier(.55,.055,.675,.19);
  }
  50% {
    inset: -4%;
    animation-timing-function: cubic-bezier(.4,0,.2,1);
  }
}
```

- **不是匀速**：关键帧内的分段缓动控制实际节奏，不能只改动画 shorthand 就以为已经改变了缓动。
- **向外呼吸**：`inset:0` 是完整基础尺寸，不从更小的形状开始；峰值四周向外扩张。
- **固定中心**：左右等量变化；不是左端锚定、右端伸缩。
- **保留轮廓**：沿同一实心路径扩张，形状不会突然切换为矩形或胶囊。
- **不动内容**：文字、图标、交互框不参与动画；手机文字的2px光学校正独立于动画。
- **一致性**：顶部导航、feed、H5底栏共用动画，不给某一处单独加失焦暂停/悬停才启动等规则。
- **可访问性例外**：`prefers-reduced-motion:reduce` 下关闭呼吸，保留完整、可读的静态选中态。

悬停/键盘focus非选中项时：灰色空心轮廓、无动画，不染成绿色。按下不能引发文字缩放或矩形闪烁。

## 参数改动规则

用户只要求快一点时只改周期；只要求小一点时只改幅度；只要求圆一点时只改几何转角。不要同时修改多个维度，也不要因为改了一排按钮而让其他端自动分叉。
