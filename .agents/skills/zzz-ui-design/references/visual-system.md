# 视觉与布局

## 视觉层级

| 层 | 当前方向 | 使用原则 |
| --- | --- | --- |
| 画布 | #121212 附近深灰，低对比点阵 | 内容可读优先，不让纹理压过正文 |
| 容器 | #080808 / #171717 / #222 等层次 | 通过层次和间距分区，不是每块都加绿边 |
| 主强调 | #d7fa00 | 选中底板、主操作、少量识别元素 |
| 悬停轮廓 | #858585 空心灰 | 非选中导航 hover/focus，静止、不填实心绿 |
| 文字 | 浅白主文、灰色辅助信息 | 标题粗重，正文留出行高，避免所有文字都斜体 |
| 首页横幅 | 大字号绳网识别、浅色海报底、右侧图像 | 用户已认可，不能因参考站没有横幅而移除 |
| 内容流 | 封面比例自然、作者信息、标题/摘要/计数 | 保持密度，但不裁断关键操作 |

背景、头像、图像资产使用合法来源；区分项目原创素材、开源代码、参考图片。不要声称第三方非官方项目就是官方设计标准。

## 桌面 Web

当前桌面布局阈值为 1025px：
- 142px 双行页头：账户/搜索工具行 + 接近占满一行的主导航。
- 页头最大宽度约1648px，主要内容最大宽度约1600px。
- feed 导航占用可用横向空间，分区筛选另列。
- 桌面隐藏 H5 底部主导航。
- 详情阅读容器与编辑器从真实页头下方开始，不复用旧78px偏移。

这些是现有实现约束，不是任何新页面都必须照抄的定值。重点是独立的宽屏信息结构和正确的高度联动。

## 手机 H5

- 紧凑页头、响应式内容流、底部连续主导航轨道。
- 底栏左右8px，底部8px + safe-area，轨道46px高/3px边框，内部40px高。
- 图标文字横排；图标18px，标签11px，间距4px。
- 发布按钮30px，不再上浮，不保留原来的大光晕。
- “推送”文字基于几何中心向右2px作光学校正；绿色底板中心不跟随这2px偏移。
- 内容底部预留足够空间，不能被底栏或安全区挡住。

不要把旧58px高、上下叠放图标文字的底栏与新底板混用。

## 自动与强制模式

- `/`：随窗口自动适配。
- `/web`：强制桌面布局视口，最小1280px，窄屏等比缩放。
- `/h5`：强制移动布局视口，最大430px，宽屏居中。

当前强制模式通过同源 iframe 建立真正独立的布局视口，使媒体查询、瀑布流及弹窗保持一致。这是 Web 模式切换，不是原生桌面客户端方案。检查样式时要测 iframe 内的真实视口，不把外层窗口宽度误当成应用宽度。

## 后续模块如何沿用

办公、媒体、消息、工具模块应共享导航/形状/字体层级，但保留各自的信息结构。例如：编辑器需要工具栏与工作区、消息页需要会话与消息层级，不要都堆成首页封面卡片。新的功能可先有诚实的空状态，不能用装饰性假数据伪装为真实接通。
